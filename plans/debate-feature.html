② 합의된 핵심 결정 4가지

시작 트리거

!debate <주제> 명령어. 봇이 자동으로 스레드를 생성하고 첫 페르소나가 발화 시작.

발화 순서

응답 본문에서 페르소나 멘션(@backend 등)을 파싱 → 멘션받은 페르소나가 다음 발화자.

종료 조건

이중 안전망: 자동 N회 제한 + !end 명시 종료.

맥락 유지

매 호출마다 스레드의 모든 메시지를 읽어서 system prompt에 누적 (claude는 stateless).

③ 새 명령어 2개

명령어위치동작
!debate <주제> 매핑된 채널의 본문 스레드 자동 생성 → 채널의 페르소나가 첫 발화
!end 토론 스레드 안 토론 종료, 마지막 페르소나가 짧은 요약 후 스레드 archive

설계 선택

  • 스레드 이름은 주제 첫 60자 (Discord 제한)
  • 스레드 부모 채널의 persona가 첫 발화자 (예: #pm에서 시작 → PM 첫 발화)
  • 일반 멘션(@bot)은 기존대로 단발 응답 — 토론은 !debate일 때만

④ 발화 순서 알고리즘

Claude가 응답할 때 본문에 다른 페르소나 키워드를 넣으면 봇이 그걸 보고 다음 발화자 결정.

구현 방식

# 페르소나 system prompt에 추가:
"다른 페르소나 의견이 필요하면 응답 마지막 줄에
@backend 또는 @frontend 또는 @pm 형식으로 멘션하세요.
멘션 없이 끝내면 토론이 자연 종료됩니다."

# 봇 코드:
def next_speaker(response_text, available_personas):
    for line in reversed(response_text.split("\n")):
        for key in available_personas:  # ["pm", "backend", "frontend"]
            if f"@{key}" in line:
                return key
    return None  # 멘션 없음 → 자연 종료

왜 진짜 Discord 멘션이 아니라 텍스트 패턴?

Webhook 메시지는 사용자 ID가 없어서 진짜 Discord 멘션의 대상이 될 수 없어요. 텍스트 마커가 유일한 방법.

⑤ 맥락 빌드 (스레드 → system prompt)

매 페르소나 호출 직전, 스레드의 모든 메시지를 읽어서 system prompt 끝에 붙임.

# 의사코드
async def build_context(thread, persona):
    history = []
    async for msg in thread.history(limit=200, oldest_first=True):
        speaker = identify_speaker(msg)  # webhook_id → 페르소나 키, 또는 "사용자"
        history.append(f"[{speaker}] {msg.content}")

    return (
        persona.read_prompt() + "\n\n"
        "=== 토론 맥락 (시간 순) ===\n"
        + "\n".join(history) + "\n\n"
        "위 맥락을 바탕으로 당신({persona}) 입장에서 응답하세요."
    )

한계와 대응

  • 맥락 폭주: 100턴 가면 system prompt가 거대해짐 → N회 자동 제한이 1차 방어선
  • 중복 정보: 매번 전체 첨부 = 토큰 낭비. 일단은 단순함 우선, 차후 압축 검토

⑦ 단계별 구현 phase

1
config + debate.py 골격 — 세션 상태 dataclass + 종료 조건 메서드. 단위 테스트.
2
webhook_manager 스레드 지원 — send/edit에 thread 인자 패스스루.
3
!debate 핸들러 — 본문 채널에서 명령 감지 → channel.create_thread() → 첫 페르소나 호출.
4
스레드 안 메시지 흐름 — webhook 발신자 식별, 페르소나 응답 파싱(@key 추출), 다음 발화자 호출.
5
!end + 자동 종료 — 라운드 카운터 초과 또는 !end 명령 → 마지막 요약 메시지 + thread.edit(archived=True).
6
페르소나 .md 업데이트 + 통합 테스트 — 실제 Discord 스레드에서 시나리오 1개 라이브 테스트.
